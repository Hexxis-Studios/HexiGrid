LOCAL CONNECTION

Reconnect to return to HexiGrid

HexiGrid hides live agents, tools, messages, and device controls while it cannot reach this device's local service. That keeps old agent or device status from looking current.

  1. Make sure HexiGrid is open on this device.
  2. Return to HexiGrid and choose Try again.
  3. If a message or task was in progress when the connection dropped, check Activity before trying again.

Your saved workspace data stays on this device; losing the connection does not delete it.
