# Changelog

## 0.0.1 Alpha 1

- Windows x64 installer and self-hosted browser app.
- Local/cloud models, external-agent Links, chats, calls, memory, workspaces, tools and backups.
- Seven-section navigation with a collapsible sidebar.
- Searchable help with screenshots that enlarge and close inside the app.
- Paired-agent removal and disconnection in the same confirmation.

See [release notes](docs/ALPHA-RELEASE-NOTES.md) for setup and limitations.
