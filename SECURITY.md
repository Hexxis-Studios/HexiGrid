# Security reports

Report suspected credential exposure, unauthorized access or other vulnerabilities privately to [contact.hexigrid@proton.me](mailto:contact.hexigrid@proton.me). Do not send credentials or private workspace files. Include the affected release, reproduction steps and potential impact.

Use [GitHub Issues](https://github.com/Hexxis-Studios/HexiGrid/issues) for ordinary bugs without sensitive details.

Install only from this repository's releases. Review agent access and keep an encrypted backup of important data. The alpha installer is unsigned; SHA-256 checksums identify the downloadable files.
